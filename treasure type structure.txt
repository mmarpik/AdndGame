How It Works:
After killing monsters, the system will:

2.	Randomly select items from the available item pool
3.	Distribute them to surviving party members
4.	Display the results in the combat rewards dialog

•	GameRules.NumberOfItemsThatCouldBeFound - maximum number of items that could be found (default: 5)
